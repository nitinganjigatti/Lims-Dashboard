# LIMS Dashboard to Review

Clickable prototype of the lab (LIMS) dashboard, for review. All data is sample data generated in the page.

- `v11.html` – the dashboard (opened by `index.html`)
- `flows.html` – Reception and Department flows, opened from "Lab-wise Requests" / "Department-wise Requests" in the sidebar
- `assets/` – icons used by the pages

Open `index.html` in a browser, or view it on GitHub Pages.
